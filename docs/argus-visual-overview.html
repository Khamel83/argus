Argus · retrieval infrastructure

Search is a system, not a single API.

Argus gives AI agents one evidence-aware retrieval layer for web search, difficult-page extraction, dead-link recovery, and durable provenance.

Portable visual overview

One authority
Production callers share policy, budgets, sessions, and evidence through authenticated HTTP.

Many surfaces
CLI for operators, HTTP for services, MCP for agent harnesses.

Argus is retrieval infrastructure—not personal memory and not a chat layer. Its job is to find, extract, rank, explain, and preserve external evidence for the system that called it.

02 · Search policy

Spend the least. Learn the most.

Argus chooses a provider queue by mode and then checks whether each option is configured, healthy, inside its budget, and appropriate for the caller before it sends a request.

Routing order

Provider pool

Tier 0 · free first

Start with recurring free capacity.

Self-hosted, scraped, public, and free-key sources carry baseline retrieval before paid capacity is considered.

Tier 1 · recurring

Use monthly capacity deliberately.

Metered providers remain available when they improve coverage and caller policy allows the tier.

Tier 3 · finite

Protect one-time credits.

Finite balances are a late fallback, not the default path for background automation.

04 · Topology & provenance

Where evidence came from matters.

Different domains behave differently from residential and datacenter egress. Argus uses observed domain behavior to avoid repeating known-bad routes, then carries provenance with the result so downstream systems can inspect the path.

05 · Choose the surface

Put retrieval where work happens.

Argus offers the same retrieval authority through different interfaces. Pick the transport that matches the caller; do not make an interactive client become a second execution authority.

Service / job

HTTP

Use direct authenticated requests for applications, automation, scheduled work, and durable service integrations.

Agent harness

MCP

Use the stateless MCP adapter for interactive tools such as coding agents and conversation-driven retrieval.

Operator / dev

CLI

Use local commands for exploration and development; production CLI still delegates to the shared HTTP authority.

The access boundary is intentional: production callers carry scoped credentials, while provider configuration and persistence remain behind the authority.
